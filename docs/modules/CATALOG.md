## Notes per module

- **abuse.ch** (`abuse_ch`): Covers URLhaus, Feodo Tracker, SSL Blacklist and MalwareBazaar. abuse.ch requires a free Auth-Key for API calls since 2025; bulk feed downloads remain open and are the preferred ingestion path for the threat_lists aggregator.
- **AbuseIPDB** (`abuseipdb`): Free key: 1,000 checks/day. Bulk blacklist export is also free at low volume.
- **Abusix Mail Intelligence** (`abusix`): DNSBL-style query with a free registered key.
- **Account Finder** (`account_finder`): Internal build: maintained site manifest (500+ sites, Sherlock/Maigret-compatible JSON), concurrent probing with per-site detectors, rate limiting and proxy rotation. Feeds social_engine.
- **ACLED** (`acled`): Free for registered non-commercial/academic use; paid otherwise. Replacement pipeline builds an equivalent event stream from GDELT, UCDP GED and ReliefWeb with NLP geocoding, refreshed hourly instead of weekly.
- **AdBlock Check** (`adblock_check`): No third-party API needed: EasyList/EasyPrivacy filter lists are freely downloadable. Implement with a filter-list matcher (adblock-rs bindings) and refresh lists daily.
- **AISStream** (`aisstream`): WebSocket stream of global AIS (terrestrial network). Free key. Subscribe with a world bounding box; de-duplicate by MMSI; keep latest position in Redis and history in the positions hypertable.
- **AlienVault IP Reputation** (`alienvault_iprep`): The legacy reputation.alienvault.com feed appears retired; verify availability, otherwise fold into OTX pulses.
- **AlienVault OTX** (`alienvault_otx`): Free API key with generous limits; keep as a first-class source inside threat_scoring.
- **Apple iTunes** (`apple_itunes`): iTunes Search API, no key.
- **Archive.org** (`archive_org`): Wayback CDX API for historical URLs; availability API for snapshots.
- **ARIN** (`arin`): Whois-RWS / RDAP, no key.
- **BGPView** (`bgpview`): Public API has been unstable at times; RIPEstat and bgp.tools are drop-in alternatives for the same data.
- **BinaryEdge** (`binaryedge`): Acquired by Coalition; free plan discontinued.
- **Bing** (`bing`): Microsoft retired the Bing Search APIs in August 2025.
- **Bing (Shared IPs)** (`bing_shared_ips`): Microsoft retired the Bing Search APIs in August 2025. Reverse-IP now comes from pdns + scanner.
- **Bitcoin Finder** (`bitcoin_finder`): Base58Check + bech32 checksum validation to avoid false positives.
- **BitcoinAbuse** (`bitcoinabuse`): Merged into Chainabuse (TRM Labs) in 2023; API endpoints differ from the original.
- **BuiltWith** (`builtwith`): Free API is extremely limited; the paid tiers are what SpiderFoot targets.
- **CallerName** (`callername`): US-only; HTML scraping, fragile.
- **CelesTrak** (`celestrak`): GP/TLE element sets for ~10k+ tracked objects. Store elements; propagate with SGP4 client-side for smooth orbits and server-side for queries. Also supports SupGP and CSV/JSON formats.
- **Censys** (`censys`): Free tier: 250 queries/month.
- **ProjectDiscovery Chaos** (`chaos`): Public bug-bounty dataset is downloadable without a key.
- **CIRCL.LU** (`circl_lu`): Free Passive DNS/SSL for security researchers; account required.
- **Clearbit** (`clearbit`): Acquired by HubSpot; the self-serve enrichment API used here was discontinued.
- **CloudFlare DNS** (`cloudflare_dns`): 1.1.1.2 (malware) and 1.1.1.3 (malware+adult) resolvers.
- **CommonCrawl** (`commoncrawl`): CDX index API; also bulk index files for offline use by pdns/subdomain_engine.
- **Comodo Secure DNS** (`comodo_dns`): Plain DNS resolver query, no key required despite the 'tiered' label; reclassified as free.
- **Company Name Extractor** (`company_name_extractor`): NER (spaCy) + legal-suffix heuristics.
- **Country Name Extractor** (`country_extractor`): Country entities resolve to a centroid at 'country' precision (rendered as a fuzzy halo, never a pin).

- **Debounce** (`debounce`): Disposable/valid checks; free credits then paid. Local disposable-domain lists cover most of this.

OpenSky itself is an optional accelerator, off by default because its terms of use appear to require a written licence for operational use of the REST API (review them before enabling): OSINT_MODULE_OPENSKY_CLIENT_ID + OSINT_MODULE_OPENSKY_CLIENT_SECRET (OAuth2 client credentials; 4,000 credits/day, a global snapshot every 86 s, 5 s resolution) or config {"opensky": {"anonymous": true}} (400 credits/day, every 14.4 min, 10 s resolution).

- **PhishTank** (`phishtank`): New API key registration has been closed for long periods; anonymous access is throttled.
- **Phone Number Extractor** (`phone_extractor`): libphonenumber matcher with region hints.
- **Port Scanner - TCP** (`port_scanner`): Async SYN/connect scanner with adaptive rate; only runs against in-scope targets.
- **Project Honey Pot** (`project_honeypot`): http:BL DNS API.
- **Psbdmp** (`psbdmp`): Intermittent availability.
- **F-Secure Riddler.io** (`riddler`): Riddler.io was retired by F-Secure/WithSecure.
- **RIPE** (`ripe`): RIPEstat Data API (also proxies ARIN/APNIC/etc. via RIR aggregation) plus RDAP.
- **RiskIQ** (`riskiq`): Community API sunset after the Microsoft acquisition (now Defender TI).
- **Amazon S3 Bucket Finder** (`s3_bucket_finder`): Name-permutation brute force against s3.amazonaws.com; lists public buckets. Merge into bucket_hunter.
- **SecurityTrails** (`securitytrails`): Free: 50 queries/month.
- **SHODAN** (`shodan`): Free key allows host lookups only at a tiny rate; search requires a paid membership.
- **Similar Domain Finder** (`similar_domains`): Permutation engine (dnstwist-compatible) cross-checked against CT logs and zone files.
- **Social Media Profile Finder** (`social_profile_finder`): Uses Google CSE quota.
- **SORBS** (`sorbs`): SORBS was shut down in June 2024.
- **SpamCop** (`spamcop`): bl.spamcop.net DNSBL.
- **Spamhaus Zen** (`spamhaus_zen`): Public mirrors for low-volume non-commercial use; DQS key otherwise.
- **spur.us** (`spur`): Replacement focuses on VPN/proxy/residential-proxy attribution from exit-node enumeration.
- **SpyOnWeb** (`spyonweb`): Replacement: index analytics/adsense IDs from our own crawls and CommonCrawl.
- **StackOverflow** (`stackoverflow`): StackExchange API is free with a key; reclassified as free.
- **Subdomain Takeover Checker** (`subdomain_takeover`): can-i-take-over-xyz fingerprints for dangling CNAMEs/NS.
- **SURBL** (`surbl`): Domain-oriented DNSBL (multi.surbl.org).
- **Talos Intelligence** (`talos`): No documented public API.
- **ThreatCrowd** (`threatcrowd`): Service shut down.
- **ThreatFox** (`threatfox`): abuse.ch Auth-Key.
- **ThreatMiner** (`threatminer`): Unreliable uptime.
- **TLD Searcher** (`tld_searcher`): Uses the IANA TLD list; batched resolution through dns_resolver.
- **Tool - Wappalyzer** (`tool_wappalyzer`): Wappalyzer closed its source in 2023; use the community-maintained fingerprint set (webappanalyzer).
- **TOR Exit Nodes** (`tor_exit_nodes`): Exit list plus Onionoo relay details (with geolocation) refreshed hourly; also runs as a feed for the tor layer.
- **TORCH** (`torch`): Onion address changes frequently.
- **Twilio** (`twilio`): Lookup v2 with caller-name add-on is billed per query.
- **Twitter** (`twitter`): X API free tier is write-only; read access is paid. Replacement scrapes public profile pages via the social_engine adapter.
- **USGS** (`usgs`): GeoJSON summary feeds (all_hour/all_day/all_week/all_month) refreshed every minute; FDSN event service for history.
- **Venmo** (`venmo`): Public transaction API was closed; profile pages may still be scrapeable.
- **VirusTotal** (`virustotal`): Free key: 4 req/min, 500/day.
- **Web Spider** (`web_spider`): Core module: polite async crawler (robots.txt aware, per-host concurrency, depth/page limits) feeding all extractors.
- **Whois** (`whois`): Core module: RDAP first (structured, rate-limit friendly), legacy WHOIS port 43 fallback with referral following.
- **WiGLE** (`wigle`): Free account with a small daily query quota; bounding-box searches populate the wifi layer for areas of interest.
- **Saildrone / Windy** (`windy_saildrone`): Windy Point Forecast API has a free key; Saildrone has no public API. Replacement uses Open-Meteo, NOAA GFS, NDBC buoys and Argo floats.
- **Yandex DNS** (`yandex_dns`): Yandex.DNS 'Safe/Family' public resolvers may have been discontinued; verify.
- **Zone-H Defacement Check** (`zone_h`): RSS feed of special defacements.
- **ZoneFile.io** (`zonefile_io`): Replacement ingests ICANN CZDS zone files directly (free with an approved account).
